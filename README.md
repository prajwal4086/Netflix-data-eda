# Netflix Data EDA

Exploratory Data Analysis of Netflix movies and TV shows using Python to identify content trends, patterns, and insights.

## Tools

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis

* Data cleaning and preprocessing
* Missing-value analysis
* Movies vs TV Shows
* Genre and rating analysis
* Release-year trends
* Country-wise content analysis
* Data visualization

## Key Insights

The analysis highlights Netflix content distribution, popular genres and ratings, country-wise trends, and changes in content availability over time.

## Conclusion

This project demonstrates the use of Python-based EDA and visualization techniques to extract meaningful insights from a real-world Netflix dataset.
